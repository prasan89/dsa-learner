# E2E QA Matrix

| Area | Coverage |
|---|---|
| Foundation | Playwright, env, traces, screenshots, reports |
| Auth | Login, refresh, logout, protected route |
| Dashboard | Load and navigation |
| DSA | Learning path, problem, hints |
| Execution | Editor, Run, Submit, result/error states |
| Mastery | Mastery surface |
| Revision | Revision route |
| Progress | Progress route |
| System Design | Landing and topic |
| Payments | Opt-in pricing/payment surface |
| Security | Protected UI, URL token leakage, error leakage |

Smoke is the fast manual QA tier. Regression is broader. Neither is wired into deployment.
