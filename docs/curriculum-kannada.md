## LinguaFlow Kannada Romanization Convention

This course uses a single consistent romanization system throughout all 800 lessons. No Kannada script appears anywhere in the core course.

### Vowels
| Sound | Romanization | Example |
|-------|-------------|---------|
| Short a | a | adu (it) |
| Long aa | aa | aata (game) |
| Short i | i | idu (this) |
| Long ii | ii | niiru (water) |
| Short u | u | adu (that) |
| Long uu | uu | huuvu (flower) |
| Short e | e | enu (what) |
| Long ee | ee | eenu (what, emphatic) |
| Short o | o | odu (to run) |
| Long oo | oo | oodi (having run) |
| ai | ai | aidu (five) |
| au | au | aula (boundary) |

### Key Conventions
- Word-final schwa: written as 'a' when pronounced (e.g., "mane" = house)
- Geminate (double) consonants written double: e.g., "akka" (sister), "amma" (mother)
- Aspirated consonants always written with 'h': kh, gh, ch, Th, Dh, ph, bh
- Retroflex capitalized: T, D, N, L, R, S, LL
- Honorific plural used for polite second/third person: neevu (you polite), avaru (they/he/she polite)

## Memory and Concept Dependency Structure

### Core Dependency Chains

```
CHAIN 1: Pronoun System
naanu/neevu/avaru (L001)
  → verb agreement (L061–L070)
    → tense formation (L201–L220)
      → reported speech (L571–L580)
        → complex discourse (L601–L700)

CHAIN 2: Case Markers
locative -alli (L081)
  → instrumental -indA (L121)
    → ablative -inda (L201)
      → complex postpositions (L301–L400)
        → formal case use (L601–L700)

CHAIN 3: Tense and Aspect
present tense (L061)
  → past tense (L201)
    → future tense (L211)
      → aspect system (L301–L400)
        → reported speech tense shifts (L571)
          → complex narrative (L601–L700)

CHAIN 4: Sentence Complexity
simple sentence (L061)
  → compound sentence (L261–L270)
    → complex sentence with subordination (L301–L400)
      → relative clause (L551–L560)
        → multi-clause discourse (L601–L700)

CHAIN 5: Register and Politeness
basic honorifics (L001–L010)
  → formal address (L535–L540)
    → register code-switching (L601–L610)
      → nuanced social language (L761–L770)

CHAIN 6: Vocabulary Depth
core 200-word vocabulary (L001–L100)
  → domain-specific vocab: shopping, health, transport (L101–L200)
    → opinion and argument vocabulary (L401–L500)
      → academic and professional vocab (L601–L700)
        → literary and idiomatic vocab (L701–L800)
```

### Memory Concept Types Per Lesson

Each lesson should define memory_concepts in these five categories:
1. **Vocabulary concepts** — specific lemmas introduced or recycled
2. **Grammar concepts** — structures practiced or extended
3. **Phrase concepts** — fixed or semi-fixed expressions
4. **Pronunciation concepts** — sound patterns highlighted
5. **Communication concepts** — pragmatic or cultural knowledge

### Concept Recurrence Policy
- Every vocabulary item introduced in Stage 1 should reappear at least 5 times before L200.
- Every grammar concept introduced in Stage 2 should be recycled in a new context by Stage 3.
- Major grammar structures (case system, tense, honorifics) reappear in every stage.
- Vocabulary from cultural lessons (festivals, food, geography) reappears in later storytelling and debate lessons.
