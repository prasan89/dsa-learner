## LinguaFlow Hindi Romanization Convention

LinguaFlow uses a single, consistent romanization system throughout all 800 lessons. This system is designed to be readable and pronounceable by English speakers.

### Vowels
| Sound | Romanization | Example |
|-------|-------------|---------|
| Short a | a | kam (less) |
| Long aa | aa | aap (you formal) |
| Short i | i | din (day) |
| Long ii | ii | liijiye (please take) |
| Short u | u | ghar (home) |
| Long uu | uu | suuraj (sun) |
| e | e | ek (one) |
| ai | ai | baith (sit) |
| o | o | log (people) |
| au | au | aurat (woman) |

### Consonants
| Sound | Romanization | Notes |
|-------|-------------|-------|
| Dental t | t | taazaa (fresh) |
| Retroflex T | T | TaaNg (leg) |
| Dental d | d | din (day) |
| Retroflex D | D | DaakTar (doctor) |
| Dental n | n | naam (name) |
| Retroflex N | N | paNDit (scholar) |
| Retroflex r | r (between vowels) | paRhna (to read) — use capital R for retroflex flap |
| Aspirated kh | kh | khana (food) |
| Aspirated gh | gh | ghar (home) |
| Aspirated ch | ch | chai (tea) |
| Aspirated jh | jh | jhaRnaa (waterfall) |
| Aspirated Th | Th | ThaNDa (cold) |
| Aspirated Dh | Dh | Dholak (drum) |
| Aspirated ph | ph | phul (flower) |
| Aspirated bh | bh | bhai (brother) |
| Nasalization | ~n or n before consonant | haa~N (yes), main (I) |
| Retroflex L | L | baLo (children, dial.) |

### Key Conventions
- **aap** = formal you (आप)
- **tum** = informal you (तुम)
- **tu** = very informal you (तू)
- **hai** = is/am/are (है)
- **hain** = are (plural/formal) (हैं)
- **ho** = are (tum form) (हो)
- **huu~N** = am (main form) (हूँ)
- **ne** = ergative marker (ने)
- **ko** = to/for (को)
- **se** = from/with/by (से)
- **mein** = in (में)
- **par** = on (पर)
- Verb infinitives end in **-naa**: jaanaa (to go), khaanaa (to eat)
